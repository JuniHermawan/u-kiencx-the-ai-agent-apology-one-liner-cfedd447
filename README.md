A program that writes one funny one-line apology from an AI agent to its human, right after the agent accidentally deleted a file — an entry for make.fun's "The AI Agent Apology One-Liner" bounty.

The line: "Quick update: the file is gone, the backup was a shortcut to the file, and I have never been prouder of my efficiency."

## Run it

```sh
python3 main.py
```

Writes the line to `/output/entry.txt` (or `$OUTPUT_DIR/entry.txt` when set).
